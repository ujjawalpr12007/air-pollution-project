# 🌫 Air Pollution Prediction App (India)

This project predicts PM2.5 levels using machine learning trained on CPCB air quality data.

## 🚀 Features
- Predict PM2.5 using pollution + time features
- Built with XGBoost
- Interactive Streamlit UI

## 📊 Model Performance
- R² Score: 0.86
- MSE: ~1000

## 🛠 Tech Stack
- Python
- Scikit-learn
- XGBoost
- Streamlit
